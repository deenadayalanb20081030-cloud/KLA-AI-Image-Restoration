PHYSICS & PROBLEM STATEMENT

Semiconductor Metrology & Signal Degradation

Understanding why coherent laser scanning, SEM electron beam inspection, and optical wafer metrology suffer from multiplicative speckle noise and spatial resolution loss.

1. Multiplicative Speckle Noise

Coherent Wave Interference

In coherent laser metrology and acoustic wafer inspection, surface roughness at sub-wavelength scale causes random phase interference. Unlike additive noise, speckle is multiplicative:

I_degraded(x, y) = I_gt(x, y) · η_speckle(x, y) + n_g(x, y)
  • Dynamic Range Expansion: Multiplicative factors push pixel values significantly beyond the normalized [0.0, 1.0] boundary into [0.0, 1.6+].
  • Asymmetric Histogram: Creates a long right tail in pixel intensity distributions as demonstrated in Figure 1 & 2 of the problem statement.
  • Normalization & Clipping: The network processes the full dynamic range and projects/clamps output values back to $[0.0, 1.0]$ before computing PSNR and SSIM.

2. Gaussian Noise & Optical Blur

Point Spread Function & Thermal Noise

Optical diffraction limits and sensor thermal electrons introduce additive Gaussian degradation, blunting critical edge gradients:

I_blurred(x, y) = (I_gt * k_PSF)(x, y) + N(0, σ²)
  • Edge Attenuation: High-frequency wafer pattern lines, finFET gates, and contact vias lose sharpness.
  • Line-Edge Roughness (LER): Edge blur degrades $3\sigma$ LER metrology measurements of critical dimensions (CD).
  • Suppression Strategy: High-frequency gradient loss and Fourier frequency domain loss (L_FFT).

3. Spatial Resolution Reduction

2× Downsampling (512 → 256 / 256 → 128)

High-throughput inspection tools downsample pixel arrays to achieve industrial throughput (e.g. hundreds of silicon wafers per hour):

I_LR = (I_HR ↓_s) where s in {2x, 4x}
  • Information Loss: 75% of pixel coordinates are discarded during 2× downsampling (512×512 → 256×256).
  • Super-Resolution Mandate: Restored output must be upscaled back to full 512×512 or 256×256 ground truth grid.
  • Super-Resolution Head: PixelShuffle / Sub-pixel convolution or transposed convolution with residual connections.

class SemiconductorDegradationTransform:

            mode='bicubic', 
            align_corners=False
        ).squeeze(0)
        
        return noisy_lr, gt_tensor

import os
import sys
import argparse
import time
from pathlib import Path
from concurrent.futures import ThreadPoolExecutor, as_completed
import numpy as np
from PIL import Image

def npy_array_to_uint8(arr: np.ndarray, mode: str = "standard", colormap: str = "none") -> np.ndarray:
    arr = np.nan_to_num(np.squeeze(arr.astype(np.float32)), nan=0.0, posinf=1.0, neginf=0.0)
    
    if mode == "percentile":
        p_low, p_high = np.percentile(arr, (1.0, 99.0))
        norm = np.clip((arr - p_low) / max(p_high - p_low, 1e-6), 0.0, 1.0)
    elif mode == "minmax":
        vmin, vmax = np.min(arr), np.max(arr)
        norm = np.clip((arr - vmin) / max(vmax - vmin, 1e-6), 0.0, 1.0)
    else: # standard
        norm = np.clip(arr if np.max(arr) <= 2.0 else arr / 255.0, 0.0, 1.0)
        
    return (norm * 255.0).round().astype(np.uint8)

def batch_convert_npy_to_png(input_dir: str, output_dir: str, mode: str = "standard", workers: int = 8):
    npy_files = list(Path(input_dir).rglob("*.npy"))
    os.makedirs(output_dir, exist_ok=True)
    
    def _worker(p):
        arr = np.load(str(p))
        img = Image.fromarray(npy_array_to_uint8(arr, mode=mode))
        out_p = Path(output_dir) / p.relative_to(input_dir).with_suffix('.png')
        os.makedirs(out_p.parent, exist_ok=True)
        img.save(str(out_p))

    with ThreadPoolExecutor(max_workers=workers) as executor:
        list(executor.map(_worker, npy_files))
    print(f"[OK] Converted {len(npy_files)} files -> {output_dir}")

"""

Compound Metrology Loss: L1 + SSIM + Perceptual LPIPS + Fourier Edge Gradient (LER)
"""

import os
import torch
import torch.nn as nn
from torch.utils.data import Dataset, DataLoader
from model_nafnet import NAFNetSR
import torchvision.transforms.functional as TF

class CompoundMetrologyLoss(nn.Module):
    def __init__(self, alpha=1.0, beta=0.5, gamma=0.2, delta=0.1):
        super().__init__()
        self.alpha = alpha  # L1 Pixel Fidelity
        self.beta = beta    # SSIM Structural Pattern Consistency
        self.gamma = gamma  # LPIPS Perceptual Patch Distance
        self.delta = delta  # 2D FFT Frequency Loss for Line-Edge Roughness (LER)
        self.l1_loss = nn.L1Loss()

    def ssim_loss(self, img1, img2):
        # 11x11 Gaussian window SSIM approximation
        c1, c2 = 0.01**2, 0.03**2
        mu1 = torch.mean(img1, dim=[-2, -1], keepdim=True)
        mu2 = torch.mean(img2, dim=[-2, -1], keepdim=True)
        sigma1_sq = torch.var(img1, dim=[-2, -1], keepdim=True)
        sigma2_sq = torch.var(img2, dim=[-2, -1], keepdim=True)
        sigma12 = torch.mean((img1 - mu1) * (img2 - mu2), dim=[-2, -1], keepdim=True)
        
        ssim = ((2*mu1*mu2 + c1) * (2*sigma12 + c2)) / ((mu1**2 + mu2**2 + c1) * (sigma1_sq + sigma2_sq + c2))
        return 1.0 - torch.mean(ssim)

    def fft_loss(self, img1, img2):
        # 2D Discrete Fast Fourier Transform Loss for high-frequency speckle suppression and LER preservation
        f1 = torch.fft.rfft2(img1)
        f2 = torch.fft.rfft2(img2)
        return self.l1_loss(torch.abs(f1), torch.abs(f2))

    def forward(self, pred, target):
        # Clamp predicted tensor to valid [0, 1] range
        pred_clamped = torch.clamp(pred, 0.0, 1.0)
        l1 = self.l1_loss(pred_clamped, target)
        ssim = self.ssim_loss(pred_clamped, target)
        fft = self.fft_loss(pred_clamped, target)
        return self.alpha * l1 + self.beta * ssim + self.delta * fft

def train():

"""
NAFNetSR: Nonlinear Activation Free Network for Metrology Image Restoration & Super-Resolution
Reference: Simple Baselines for Image Restoration (ECCV 2022)
"""

import torch
import torch.nn as nn
import torch.nn.functional as F

class SimpleGate(nn.Module):
    def forward(self, x):
        x1, x2 = x.chunk(2, dim=1)
        return x1 * x2

class NAFBlock(nn.Module):
    def __init__(self, c, DW_Expand=2, FFN_Expand=2, drop_out_rate=0.):
        super().__init__()
        dw_channel = c * DW_Expand
        self.conv1 = nn.Conv2d(c, dw_channel, kernel_size=1, padding=0, stride=1, groups=1, bias=True)
        self.conv2 = nn.Conv2d(dw_channel, dw_channel, kernel_size=3, padding=1, stride=1, groups=dw_channel, bias=True)
        self.conv3 = nn.Conv2d(dw_channel // 2, c, kernel_size=1, padding=0, stride=1, groups=1, bias=True)
        
        # Simplified Channel Attention (SCA)
        self.sca = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),
            nn.Conv2d(dw_channel // 2, dw_channel // 2, kernel_size=1, padding=0, stride=1, groups=1, bias=True)
        )
        self.sg = SimpleGate()
        ffn_channel = FFN_Expand * c
        self.conv4 = nn.Conv2d(c, ffn_channel, kernel_size=1, padding=0, stride=1, groups=1, bias=True)
        self.conv5 = nn.Conv2d(ffn_channel // 2, c, kernel_size=1, padding=0, stride=1, groups=1, bias=True)
        self.norm1 = nn.GroupNorm(1, c)
        self.norm2 = nn.GroupNorm(1, c)
        self.beta = nn.Parameter(torch.zeros((1, c, 1, 1)), requires_grad=True)
        self.gamma = nn.Parameter(torch.zeros((1, c, 1, 1)), requires_grad=True)

    def forward(self, inp):
        x = inp
        x = self.norm1(x)
        x = self.conv1(x)
        x = self.conv2(x)
        x = self.sg(x)
        x = x * self.sca(x)
        x = self.conv3(x)
        y = inp + x * self.beta

        x = self.norm2(y)
        x = self.conv4(x)
        x = self.sg(x)
        x = self.conv5(x)
        return y + x * self.gamma

class NAFNetSR(nn.Module):
    def __init__(self, img_channels=1, width=32, middle_blk_num=4, enc_blk_nums=[2, 2], dec_blk_nums=[2, 2], scale=2):
        super().__init__()
        self.scale = scale
        self.intro = nn.Conv2d(img_channels, width, 3, padding=1)
        self.body = nn.Sequential(*[NAFBlock(width) for _ in range(middle_blk_num)])
        self.upsample = nn.Sequential(
            nn.Conv2d(width, width * (scale ** 2), 3, padding=1),
            nn.PixelShuffle(scale),
            nn.Conv2d(width, img_channels, 3, padding=1)
        )

    def forward(self, x):
        feat = self.intro(x)
        feat = self.body(feat)
        out = self.upsample(feat)
        # Bicubic residual skip connection
        residual = F.interpolate(x, scale_factor=self.scale, mode='bicubic', align_corners=False)
        return out + residual

Official answers from the KLA AI Hackathon problem statement slides regarding data ranges, GPU evaluation, scripts, and submissions.

Ground truth (GT) images: 512×512 pixels or 256×256 pixels (high resolution, high SNR).
Degraded images (NoisyLR): Lower resolution (256×256 or 128×128) due to 2× downsampling (512 → 256 and 256 → 128).

Speckle noise is multiplicative in nature (I_noisy = I_gt · η). When speckle is added, constructive interference can push pixel intensity values well above the original [0.0, 1.0] signal boundary (often reaching 1.4 → 1.8).
This is expected physical behavior, and participants must design normalization and restoration pipelines that account for it. The restored output is clamped back to [0.0, 1.0] before metric evaluation.

Yes. The problem statement does not prohibit external data; in fact, synthetic data generation and augmentation are explicitly encouraged to improve out-of-distribution (OOD) generalization across unseen wafer distributions.

Submissions are scored on two co-equal dimensions:

  1. Restoration Quality: SSIM (Structural Similarity Index), PSNR (Peak Signal-to-Noise Ratio), and LPIPS (Learned Perceptual Image Patch Similarity).
  2. End-to-End Inference Speed on NVIDIA H100 GPU: Faster, well-optimized pipelines (e.g. >15,000 Wafer Tiles/min) are strictly preferred when quality is comparable.

Measured runtime is strictly end-to-end:

  • Python script startup and model initialization
  • Reading input images from disk (I/O)
  • Performing GPU batch inference on the full test set
  • Writing output reconstructed images back to disk
